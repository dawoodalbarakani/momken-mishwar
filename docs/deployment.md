# النشر والمتطلبات الخارجية

## 1. تشغيل محلي (ما يلزم على جهاز المطوّر)

```bash
cp .env.example .env
npm run db:up                         # PostgreSQL+PostGIS في Docker
export DATABASE_URL=postgres://mishwar:mishwar_dev_only@localhost:5432/mishwar
npm run db:migrate                    # يطبّق 0001 و0002 مرة واحدة لكل منهما
npm run db:seed:reference             # بيانات مرجعية وهمية: صنعاء، أنواع مركبات، إعدادات المطابقة، كتالوج المستندات
npm install && npm run test:domain
```
أوامر `start:dev` و`test:e2e` وبذر المستخدمين والتعرفة التجريبية والرحلات التجريبية (يحتاج مستخدم موظف وكلمات مرور مجزأة، ويرفض العمل في الإنتاج) تُضاف مع هيكل Nest (المرحلة B-2) وتُحدَّث هنا.

## 2. قرارات وخدمات خارجية يجب حسمها (لا يمكن للكود حسمها)

| البند | لماذا | حالة الكود |
|---|---|---|
| مزود رسائل OTP يعمل في اليمن (SMS/واتساب) وتكلفته وقابلية الوصول لمشغلي الاتصالات المحليين | بدونه لا تسجيل حقيقي | واجهة `OtpSender` + محوّل `console` للتطوير فقط |
| مزود الخرائط/البحث عن العناوين/التوجيه وتغطيته الفعلية في صنعاء وتسعيره وشروطه | لا نفترض دقة التغطية ولا أنها مجانية | طبقة تجريد `MapProvider` (مخطط) |
| Firebase Cloud Messaging: مشروع ومفاتيح وملفات `google-services.json` / `GoogleService-Info.plist` | الإشعارات | محوّل مخطط؛ لا مفاتيح في المستودع |
| تخزين كائنات S3-compatible للمستندات | رفع وثائق السائقين | حقول `.env.example` فارغة |
| الاستضافة والمنطقة وHTTPS/WSS ونسخ احتياطي لقاعدة البيانات واستعادتها | الإنتاج | لم يبدأ (`infrastructure/deployment`) |
| دراسة تعرفة السوق في صنعاء (أساس/كم/دقيقة/حد أدنى/عمولة) | كل أرقام البذر وهمية | الإدارة تضبطها من لوحة التسعير |
| المراجعة القانونية/الترخيص: وثائق السائق المطلوبة، متطلبات تشغيل خدمة نقل، حماية البيانات | لا نخترع متطلبات قانونية | الكتالوج `document_types` قابل للتهيئة |
| حدود صنعاء الفعلية وأحياؤها (GeoJSON مسحي) | البذر مستطيل تقريبي | استبدال سجل `service_areas.boundary` |
| سياسة الإلغاء والرسوم والنزاعات وجهة الاستجابة للطوارئ | قرارات تشغيلية | رمز السبب والفاعل مخزنان؛ السياسة تُكتب لاحقًا |
| سياسة الاحتفاظ بالمواقع | خصوصية | `docs/database-design.md` §7 |

## 3. قائمة قبل الإنتاج (Go-live gate)

- [ ] الترحيلات والمحفزات مطبّقة ومختبرة على PostgreSQL فعلي (غير منجز بعد).
- [ ] اختبارات التزامن تمر مرارًا (غير منجز بعد).
- [ ] `NODE_ENV=production` يمنع `OTP_PROVIDER=console` وأي بذر للحسابات التجريبية.
- [ ] أسرار الإنتاج في مدير أسرار لا في الملفات.
- [ ] نسخ احتياطي واستعادة مجرّبان لقاعدة البيانات.
- [ ] مراجعة ASVS/MASVS للبنود المختارة.
- [ ] قرار قانوني مكتوب في الوثائق والترخيص.
