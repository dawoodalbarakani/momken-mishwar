# الأمان

مراجع الاختبار: OWASP ASVS (الخادم والويب) وOWASP MASVS (تطبيقات الهاتف). عمود **الحالة**: `منفّذ+مختبر` = موجود ومشغَّل اختباره، `مكتوب` = موجود دون تشغيل، `مخطط` = تصميم فقط.

| الخطر | الضابط | الحالة |
|---|---|---|
| تخمين رمز بدء الرحلة | رمز مشتق بـ HMAC من `(ride_id, nonce)`؛ لا يُخزَّن؛ صلاحية محدودة؛ عدّاد محاولات يُزاد ذريًا في SQL قبل التحقق؛ مقارنة ثابتة الزمن | منفّذ+مختبر (`start-code.ts`) |
| السائق يبدأ الرحلة دون العميل | `TRIP_STARTED` يتطلب `startCodeVerified`؛ الرمز يراه العميل المالك فقط والسائق يدخله يدويًا | منفّذ+مختبر (آلة الحالات) |
| سائق/عميل يغيّر رحلة ليست له | فحص الدور والملكية في `ride-state.ts` ثم في الخدمة؛ محفز قاعدة يجمّد الرحلات المنتهية ويثبّت المسار والسعر | منفّذ+مختبر (النطاق)، مكتوب (المحفز) |
| التلاعب بالأجرة | الخادم وحده يسعّر؛ `quoted_total` و`price_breakdown` غير قابلين للتعديل؛ `MANUAL` يتطلب موظفًا مخولًا ويُدقَّق | منفّذ+مختبر (`pricing.ts`)، مكتوب (المحفز) |
| تكرار عملية مالية | مفاتيح idempotency في `driver_ledger_entries` وفهرس فريد لكل رحلة؛ سجل مالي غير قابل للتعديل | منفّذ+مختبر (بناء القيود)، مكتوب (القيود والمحفزات) |
| تجاوز الصلاحيات (RBAC) | أدوار في `user_roles`؛ حراس NestJS على الخادم؛ الدعم لا يملك صلاحيات مالية تلقائيًا | مخطط |
| سرقة/إعادة استخدام Refresh Token | تدوير مع `family_id`؛ استخدام توكن مُدوَّر يلغي العائلة كلها؛ تخزين الهاش فقط | مخطط (الجدول مكتوب) |
| تخمين OTP / إغراق الرسائل | هاش للرمز، `max_attempts`، مهلة، حدود إعادة إرسال، Rate limiting بالرقم وIP | مخطط (الجدول مكتوب) |
| OTP تجريبي في الإنتاج | `OTP_PROVIDER=console` يمنع الخادم من الإقلاع عندما `NODE_ENV=production`؛ لا رمز ثابت في أي تطبيق | مخطط |
| حسابات تجريبية في الإنتاج | سكربت البذر يرفض العمل في الإنتاج؛ كلمات المرور التجريبية تُولَّد وتُطبع في بيئة التطوير فقط | مخطط |
| تسريب مواقع | الوصول لسجل المواقع بصلاحية وبعلاقة رحلة فقط؛ نافذة احتفاظ قصيرة؛ لا يرى السائق موقع العميل إلا أثناء رحلة مسندة له | مخطط |
| عرض موقع قديم كأنه مباشر | عمر الموقع يُرسل ويُعرض؛ العتبة من `dispatch_settings.location_max_age_seconds` | مخطط |
| رفع مستندات خبيثة | قائمة MIME مسموحة، حد الحجم، مفتاح تخزين عشوائي، روابط موقّعة قصيرة العمر، لا روابط عامة | مخطط (القيد مكتوب) |
| فقدان أثر العمليات الحساسة | `audit_logs` غير قابل للتعديل: اعتماد/تعليق سائق، تغيير تعرفة، تسويات، دخول الإدارة | مخطط (الجدول والمحفز مكتوبان) |
| أسرار في المستودع أو التطبيقات | `.env.example` بقيم وهمية؛ `.gitignore` يمنع المفاتيح؛ لا أسرار في Flutter (مفاتيح الخرائط تُقيَّد بالحزمة/المنصة من لوحة المزود) | مكتوب |
| اعتراض الاتصال | HTTPS/WSS فقط في الإنتاج؛ قاعدة البيانات غير مكشوفة للعامة (Compose يربطها على localhost) | مكتوب (Compose) |

## الإبلاغ والطوارئ

نوفّر: زر «أبلغ عن مشكلة» في الرحلة، فئة `SAFETY_INCIDENT` في `support_tickets` تظهر أولًا في لوحة الدعم، وعرض بيانات اتصال الدعم. **لا ندّعي وجود استجابة طوارئ** إلا بعد ربطها فعليًا باتفاق مع جهة واختبارها.
