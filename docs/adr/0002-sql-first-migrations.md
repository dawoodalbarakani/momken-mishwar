# ADR-0002: ترحيلات SQL أولًا

**الحالة:** مقبول. **القرار:** مصدر الحقيقة ملفات `database/migrations/*.sql` المُراجَعة يدويًا وتُطبَّق بـ `run-migrations.sh` (جدول `schema_migrations`، كل ترحيل في معاملة). Prisma يُستخدم للوصول (`db pull`) لا لتوليد الترحيلات.
**السبب:** الاعتماد على PostGIS (`geography`)، والمحفزات، والفهارس الجزئية، والقيود المؤجلة — وPrisma Migrate لا يعبّر عنها بشكل سليم؛ والمراجعة اليدوية مطلوبة صراحةً.
**الثمن:** لا مقارنة تلقائية بين `schema.prisma` والقاعدة؛ يُغطّى بخطوة CI تشغّل الترحيلات ثم `prisma db pull` وتفشل عند الاختلاف.
