# ADR-0004: الإسناد الذرّي بقيود PostgreSQL لا بفحص التطبيق

**الحالة:** مقبول. **القرار:** الحماية من التعارض بأربع طبقات: تحديث مشروط داخل معاملة، فهارس فريدة جزئية (`ride_offers_one_accepted_uq`, `rides_one_active_per_driver_uq`)، محفزات `guard_*`، ومحفز مؤجَّل لتطابق العرض مع الرحلة. التفاصيل والجدول في `database-design.md` §3.
**بدائل رُفضت:** قفل استشاري على مستوى التطبيق (يُنسى عند مسار جديد)، Redis lock (نقطة فشل إضافية وليس مصدر الحقيقة).
**اختبار القبول:** اختبارات التزامن في `testing.md` على PostgreSQL فعلي — **لم تُشغَّل بعد**.
