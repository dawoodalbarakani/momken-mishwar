# ADR-0001: Monorepo والحزمة التقنية

**الحالة:** مقبول. **القرار:** مستودع واحد (`apps/`, `packages/`, `database/`, `infrastructure/`, `docs/`)؛ NestJS + PostgreSQL/PostGIS + Prisma للخادم، Flutter (Riverpod, GoRouter, Dio) للتطبيقين، Next.js للإدارة، كما في المتطلبات.
**السبب:** عقد API واحد وتغييرات ذرّية عبر المنتجات الأربعة. **الثمن:** CI أثقل؛ نخففه بتشغيل المهام حسب المسارات المتغيرة.
**قيد معروف:** إصدارات الحزم تُثبَّت عند أول `npm install`/`flutter pub get` على جهاز بشبكة وتُسجَّل في ملفات القفل؛ لم تُحسم هنا لأن بيئة الكتابة بلا شبكة.
