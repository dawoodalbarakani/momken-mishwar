# ADR-0005: تمثيل المال

**الحالة:** مقبول. **القرار:** `NUMERIC(18,2)` + `currency_code` في القاعدة؛ أعداد صحيحة بالوحدة الصغرى في الشيفرة؛ تقريب نصف-للأعلى بـ BigInt؛ العمولة تُحسب مرة وتُخزَّن؛ دفتر الأستاذ لا يعيد الحساب. لا خلط بين العملات (`CURRENCY_MISMATCH`/`MIXED_CURRENCY`).
**السبب:** منع أخطاء الفاصلة العائمة، وجعل أي فرق مطابقة قابلًا للتفسير وحدة وحدة.
