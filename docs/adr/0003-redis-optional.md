# ADR-0003: Redis وBullMQ اختياريان في الإصدار الأول

**الحالة:** مقبول. **القرار:** لا يُشترط Redis للإقلاع. انتهاء العروض ومهلة البحث وتنظيف OTP/الاحتفاظ تعالجها مهام دورية داخل الخادم تقرأ `expires_at` من PostgreSQL (تصمد أمام إعادة التشغيل). Rate limiting: عدّادات في الذاكرة لنسخة واحدة، ويُنتقل إلى Redis عند تشغيل أكثر من نسخة.
**متى نضيف Redis:** (1) أكثر من نسخة API، (2) حمل تحديثات موقع يتجاوز ما تتحمله القاعدة، (3) fan-out لـ WebSocket عبر نسخ. عندها يُكتب ADR جديد بالقياس. Compose يضعه تحت profile `redis`.
