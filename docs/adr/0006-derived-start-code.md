# ADR-0006: رمز بدء الرحلة مشتق لا مخزَّن

**الحالة:** مقبول. **القرار:** `code = HMAC-SHA256(secret, ride_id ‖ nonce)` مقتطعًا إلى 4 خانات؛ القاعدة تحفظ `nonce` والانتهاء والعدّاد فقط. العميل المالك يستعيد الرمز عبر الخادم بعد إعادة فتح التطبيق؛ السائق لا يستلمه أبدًا.
**السبب:** تسريب القاعدة وحده لا يكشف رموزًا؛ لا حاجة لتخزين قابل للعكس. **الأمان العملي** مصدره العدّاد (5 محاولات من 10⁴) والانتهاء، لا طول الرمز. يمكن رفع الخانات (حتى 8) دون تغيير المخطط.
